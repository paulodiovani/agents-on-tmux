What is AOT?

Agents on TMUX (AOT) is a Rust binary that works as a thin wrapper over TMUX and a TUI control panel. It creates an isolated TMUX server for your AI coding agents, giving each one its own window — no conflicts with your existing sessions.

The TUI panel lets you see which agents are running, focus between them, rename windows, and start new agents. It uses standard TMUX keybindings, so there's nothing new to learn. If you already use TMUX, you already know how to use AOT.

Features

Isolated Sessions

Each agent runs in its own TMUX window on a dedicated server (-L agents-on-tmux), preventing conflicts with your existing TMUX sessions.

TUI Control Panel

Manage agents with a terminal UI — focus, rename, stop, or start new agents. Two tabs: Agents for AI coding agents, Windows for regular TMUX windows.

TMUX Muscle Memory

Uses standard TMUX keybindings — no new shortcuts to learn. AOT leverages your existing TMUX knowledge so you can be productive from the first second.

Multi-Agent Support

Detects and controls popular AI coding agents: Claude Code, Codex, Aider, Copilot, Cursor, Devin, Hermes, OpenCode, Pi, and more.

Flexible Launch Modes

Split pane (default), standalone TUI (--tui), or headless attach (--no-tui). Choose what fits your workflow.

Icon Support

Nerd Font and Font Awesome icons for visual agent identification. See at a glance which agent is running in each window.

frontends/tui

The terminal control panel built with ratatui. Provides a sidebar with two tabs: Agents (running AI coding agents) and Windows (regular TMUX windows). The TUI runs in its own TMUX pane and retains its width when the terminal is resized.

backends/tmux

The TMUX communication interface. Manages the isolated TMUX server using -L agents-on-tmux, creates sessions, handles window CRUD, and provides the Tmux trait for interacting with TMUX programmatically.

backends/agents

Agent detection and identification. Recognizes popular AI coding agents (Claude Code, Codex, Aider, Copilot, Cursor, Devin, Hermes, OpenCode, Pi) by name and command, enabling the TUI to display appropriate icons and metadata.

Installation

Requirements

  • • TMUX
  • • Optional: Nerd Font 3+ for agent icons
  • • Optional: Font Awesome 7+ for agent icons

Build from source

Requires Rust 1.85+ (edition 2024). 

# Clone the repository
git clone https://github.com/diovani/agents-on-tmux.git
cd agents-on-tmux

# Build and install
cargo install --path .

Configuration

AOT supports CLI arguments, environment variables, and a TOML config file at ~/.config/aot/aot.conf.

Priority chain: CLI arguments > environment variables > config file > defaults 

# ~/.config/aot/aot.conf
tui = false
tui_width = 35
nerd_font = true
font_awesome = true
debug = false

Quick Start

Launch modes

# Start AOT in your TMUX session (default: split pane with TUI)
aot

# Launch standalone TUI only
aot --tui

# Run without TUI (headless attach to nested session)
aot --no-tui

# Adjust TUI panel width
aot --tui-width=50

How it works

  1. Start the application with aot
  2. AOT checks if a parent TMUX session is running (stops if not)
  3. Creates an isolated TMUX server using tmux -L agents-on-tmux
  4. The TUI control panel opens in a left pane (configurable width)
  5. Use the TUI or standard TMUX bindings to manage agents

Alternatives

herdr

A full agent runtime with persistent server, multi-machine support, and cloud features. Much more ambitious than AOT.

Key differences:

  • • herdr runs a background server; AOT relies on TMUX sessions
  • • herdr supports multiple machines via SSH; AOT is single-machine
  • • herdr has a plugin ecosystem and cloud features (coming soon)
  • • AOT is minimal and self-contained; no daemon required
  • • AOT leverages existing TMUX knowledge; herdr has its own interface
  • • Both support similar agents (Claude Code, Codex, OpenCode, etc.)

tmux + claude code

Documentation/guide for manually setting up TMUX with Claude Code. Not a tool, just setup instructions.

Key differences:

  • • Not a tool, just a setup guide for manual TMUX configuration
  • • Requires users to configure TMUX themselves
  • • Only covers Claude Code; AOT supports multiple agents
  • • No TUI control panel or agent detection
  • • AOT automates the setup and provides orchestration features
